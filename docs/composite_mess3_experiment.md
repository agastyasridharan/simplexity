# Composite Mess3 Experiment: Hierarchical Belief State Geometry in Transformers

## What this experiment is about

The paper "Transformers Represent Belief State Geometry in their Residual Stream" (Shai et al., NeurIPS 2024) showed that when a small transformer is trained on sequences generated by a Hidden Markov Model (HMM), its residual stream linearly encodes the Bayesian posterior over hidden states — the "belief state." This was demonstrated for flat (single-layer) HMMs.

This experiment asks: **does the same hold for a hierarchical HMM, where a slow latent variable (the "driver") selects between two different HMM variants?** The transformer must simultaneously infer which variant is active AND track the fast-changing state within that variant — two inference problems operating at different timescales.

## The composite process

### The building block: Mess3

Each Mess3 variant is a 3-state HMM that emits tokens from a vocabulary of three symbols {A, B, C}. Each hidden state has a "preferred" symbol that it emits most often. The parameter `a` controls how peaked this preference is.

**Variant A** (a=0.85) — strong preferences:

| Hidden state | P(emit A) | P(emit B) | P(emit C) |
|---|---|---|---|
| State 1 | **0.773** | 0.114 | 0.114 |
| State 2 | 0.114 | **0.773** | 0.114 |
| State 3 | 0.114 | 0.114 | **0.772** |

**Variant B** (a=0.65) — weaker preferences:

| Hidden state | P(emit A) | P(emit B) | P(emit C) |
|---|---|---|---|
| State 1 | **0.603** | 0.199 | 0.199 |
| State 2 | 0.199 | **0.603** | 0.199 |
| State 3 | 0.199 | 0.199 | **0.603** |

The key difference: under variant A, seeing an A is strong evidence for state 1 (77% vs 11%). Under variant B, the same observation is weaker evidence (60% vs 20%). Variant B produces more "noisy" sequences with less predictable patterns.

### The hierarchical structure

A slow-switching "driver" randomly selects between these two variants. At each time step, with probability epsilon=0.05 (5%), the driver switches to the other variant. This means the driver stays in one regime for roughly 20 steps on average before switching.

The composite process has **6 hidden states**: (driver, transducer state) pairs. They are ordered as:

| Index | Driver | Transducer state |
|---|---|---|
| 1 | A | State 1 |
| 2 | A | State 2 |
| 3 | A | State 3 |
| 4 | B | State 1 |
| 5 | B | State 2 |
| 6 | B | State 3 |

The transition matrix has a block structure. When the driver is currently A, the transducer follows variant A's dynamics regardless of whether the driver simultaneously switches:

```
T^(y) = | (1-eps) * T_A^(y)    eps * T_A^(y)   |
        |   eps * T_B^(y)    (1-eps) * T_B^(y)  |
```

This is a (3, 6, 6) array — one 6x6 matrix per observation symbol. The stationary distribution is uniform: each of the 6 states has probability 1/6.

### A concrete example: watching beliefs evolve

Imagine we observe the sequence: **A A C A A A B A A A A A C A A**

Starting from complete ignorance (uniform prior over all 6 states), here is how the Bayesian belief state evolves. The column "theta" is P(driver=A), the probability we are in variant A:

| Token | Position | theta (driver A prob) | Transducer marginal (S1, S2, S3) |
|---|---|---|---|
| — | start | 0.500 | [0.333, 0.333, 0.333] |
| A | 1 | 0.500 | [0.750, 0.125, 0.125] |
| A | 2 | 0.580 | [0.924, 0.038, 0.038] |
| C | 3 | 0.437 | [0.572, 0.064, 0.364] |
| A | 4 | 0.455 | [0.868, 0.032, 0.099] |
| A | 5 | 0.526 | [0.953, 0.017, 0.030] |
| A | 6 | 0.586 | [0.973, 0.012, 0.015] |
| B | 7 | 0.451 | [0.654, 0.296, 0.050] |
| A | 8 | 0.458 | [0.902, 0.073, 0.025] |
| A | 9 | 0.522 | [0.961, 0.024, 0.015] |
| A | 10 | 0.581 | [0.974, 0.014, 0.012] |
| A | 11 | 0.630 | [0.978, 0.011, 0.011] |
| A | 12 | 0.670 | [0.980, 0.010, 0.010] |
| C | 13 | 0.533 | [0.647, 0.045, 0.309] |
| A | 14 | 0.530 | [0.908, 0.023, 0.070] |
| A | 15 | 0.585 | [0.965, 0.014, 0.021] |

Notice two things:

1. **The transducer marginal moves fast.** After just 2 A's in a row, the belief strongly favors state 1 (0.924). After a C interrupts, it shifts toward state 3, but quickly recovers with the next A. This variable synchronizes in 2-3 tokens.

2. **The driver marginal moves slowly.** It drifts between 0.43 and 0.67 over 15 tokens, never becoming very confident. This is because each token provides only a small amount of evidence about which variant is active — the KL divergence between variants is about 0.065 nats per token. Reaching 95% confidence requires roughly 30 tokens of consistent evidence.

The central question of this experiment: does a transformer trained to predict the next token in these sequences internally represent this 6D belief state, including the slowly-evolving driver probability?

## The transformer

### Architecture

The transformer follows the architecture in Shai et al. (Appendix A.6), extended to a longer context window:

| Parameter | Value | Why |
|---|---|---|
| Context length (N_CTX) | 50 | Long enough to observe driver switching (~20-step dwell time) |
| Model dimension (d_model) | 64 | Same as the paper |
| Attention heads | 1 | Same as the paper |
| Head dimension | 8 | Same as the paper |
| Layers | 4 | Same as the paper |
| MLP dimension | 256 | Same as the paper |
| Vocabulary size | 3 | {A, B, C} |
| Activation | ReLU | Same as the paper |
| Normalization | Layer Norm | Same as the paper |
| Total parameters | 145,635 | — |

The context length of 50 (vs 10 in the paper) is the key architectural difference. With N_CTX=10, the model could see at most 10 tokens — not nearly enough to infer the driver with any confidence. With N_CTX=50, the model has enough context to observe a driver regime (~20 tokens), accumulate statistical evidence, and potentially observe a switch.

### Training

| Parameter | Value |
|---|---|
| Optimizer | SGD |
| Learning rate | 0.01 |
| Batch size | 64 |
| Training steps | 1,000,000 |
| Data | Fresh batches sampled from stationary distribution each step |

The model is trained on standard next-token prediction: given tokens at positions 0 through t, predict the token at position t+1. The loss is cross-entropy.

### Training convergence

The model converges to a smoothed loss of **0.931 nats** (averaged over the last 10K steps). The theoretical minimum loss — the entropy rate of the composite process — is **0.929 nats**. The gap is 0.002 nats (0.22%).

What do these numbers mean concretely?

- **1.099 nats** is the entropy of a uniform distribution over 3 symbols (log 3). A model that always predicts each symbol with probability 1/3 would achieve this loss.
- **0.929 nats** is the best any model could achieve, even with infinite context and perfect inference. The composite process has structure (runs of similar tokens, state persistence) that makes some tokens partially predictable.
- **0.931 nats** means the model assigns, on average, about 39.4% probability to the correct next token. For comparison, random guessing gives 33.3%. The process is close to uniform — most of the structure is subtle — so even optimal prediction only modestly beats random.

The 0.22% gap above optimal likely reflects the finite context window: with only 50 tokens of history, the model cannot perfectly resolve driver state from very old observations. The loss fully plateaued by step 600K — additional training would not reduce it further.

## Probing methodology

### How the probe works

After training, we freeze the model and ask: is the 6D belief state linearly readable from the residual stream?

The procedure:
1. Generate 50,000 fresh sequences of 50 tokens each from the composite process.
2. Compute the exact Bayesian belief state at every position using the known transition matrices. This gives 2,500,000 belief vectors (50,000 sequences × 50 positions), each a 6D probability distribution.
3. Run each sequence through the trained transformer and extract the residual stream activations at every position. Each activation is a 64D vector (per layer) or 256D (concatenating all 4 layers).
4. Fit an ordinary least squares (OLS) linear regression: activations → belief states.
5. Measure how well the linear prediction matches the true belief state, using MSE and R².

The regression has the form: **predicted_belief = W × activations + b**, where W is a matrix and b is a bias. For the concatenated probe, this is a 6×257 matrix (256D activations + intercept, mapping to 6D beliefs). There are 1,542 free parameters fit to 2,500,000 data points — a ratio of 1,621:1, making overfitting negligible.

### What R² means in this context

R² = 1 - (sum of squared prediction errors) / (sum of squared deviations from the mean).

- **R² = 0** means the linear probe does no better than predicting the mean belief state at every position. The mean belief is approximately [1/6, 1/6, 1/6, 1/6, 1/6, 1/6] (uniform), so R²=0 means the probe cannot track how beliefs deviate from uniform.
- **R² = 1** means the linear probe perfectly recovers the true belief state at every position.
- **R² = 0.98** means the linear probe captures 98% of the variance in belief states. The remaining 2% is either nonlinearly encoded or not present in the residual stream.

### What MSE means in this context

MSE is the average squared Euclidean distance between predicted and true belief vectors, averaged over all 2,500,000 data points:

MSE = (1/N) × sum over all data points of ||true_belief - predicted_belief||²

The MSE of 0.0043 (concatenated probe) corresponds to an RMS error of **0.027 per component** of the 6D belief vector. Since each component is a probability between 0 and 1, this means the probe predicts each component to within about ±0.03 on average. For example, if the true belief has P(driver=A, state=1) = 0.45, the probe would typically predict a value between 0.42 and 0.48.

### Why we report both R² and MSE

R² is a normalized metric that accounts for how much variance exists in the targets. MSE is an absolute metric. They can tell different stories when the baseline changes:

- The untrained model has R²=0.70 and MSE=0.071.
- The trained model has R²=0.98 and MSE=0.004.

Looking at R², it seems like the architecture does 70% of the work and training adds 28%. Looking at MSE, training provides a 16.4x improvement (0.071 → 0.004), reducing error by 94%. MSE is the more honest metric for assessing training's contribution, because R² is dominated by the large variance between "near-uniform" beliefs (early positions) and "confident" beliefs (later positions), which even the untrained model can partially capture.

## Results

### Per-layer probe results

| Layer | Full belief R² | Full belief MSE | Driver R² | Transducer R² |
|---|---|---|---|---|
| L0 (first layer) | 0.874 | 0.0296 | 0.556 | 0.954 |
| L1 | 0.907 | 0.0220 | 0.632 | 0.981 |
| L2 | 0.943 | 0.0135 | 0.868 | 0.988 |
| L3 (final layer) | 0.956 | 0.0103 | 0.895 | 0.994 |
| Concat (all layers) | **0.982** | **0.0043** | **0.943** | **0.998** |

**Important caveat about driver and transducer probes:** The driver marginal theta = sum of the first 3 components of the 6D belief. The transducer marginal = sum of paired components (eta[0]+eta[3], eta[1]+eta[4], eta[2]+eta[5]). Both are linear functions of the full belief. This means their R² values are mathematically derived from the full-belief probe — they are decompositions of a single result, not independent evidence. Any linear map that recovers the full 6D belief automatically recovers theta and mu.

With that caveat, the per-layer pattern is meaningful:

**Transducer R² is high from L0 onward (0.954).** The transducer state is a "fast" variable — it's tightly constrained by the most recent few tokens. Knowing "the last two tokens were both A" already makes state 1 very likely (see the belief evolution table above). Even the first layer captures this.

**Driver R² grows progressively through layers (0.556 → 0.895).** The driver is a "slow" variable — it requires integrating subtle statistical evidence over many tokens. At L0, the network has barely begun this computation. By L3, after four layers of processing, it has substantially resolved the driver identity. But the improvement from L0 to L3 is continuous — there is no single layer where driver inference "happens."

**Concatenated is substantially better than any single layer.** The full-belief MSE drops from 0.0103 (L3 alone) to 0.0043 (all layers concatenated) — a 2.4x improvement. This means belief information is distributed across layers. Each layer contributes unique information that no other layer redundantly contains.

### Controls

Five controls validate that the probe results are genuine.

#### Sequence-level cross-validation (MSE = 0.0044, ratio = 1.00x)

The probe is trained on 20% of sequences (10,000 sequences, all 50 positions) and tested on the remaining 80% (40,000 sequences). The test MSE (0.0044) is indistinguishable from the full-data MSE (0.0043). This rules out overfitting. The linear relationship between activations and beliefs generalizes perfectly to unseen sequences.

This control holds out entire sequences, not individual data points. This is important because consecutive positions within a sequence have correlated activations and beliefs (position 10 and position 11 of the same sequence have similar beliefs and similar activations). Holding out entire sequences is a stricter test.

#### Shuffle (MSE = 0.236, ratio = 54.2x)

The correspondence between activations and beliefs is randomly permuted (each activation is paired with a randomly chosen belief from a different position/sequence). The MSE jumps 54x. This confirms that the probe is detecting genuine structure linking specific activations to specific beliefs, not finding spurious correlations in high-dimensional data.

For reference, 0.236 is the MSE you'd expect from always predicting the mean belief [1/6, ..., 1/6], which is approximately the variance of the belief targets.

#### Untrained model baseline (MSE = 0.071, R² = 0.697, ratio = 16.4x)

A randomly initialized transformer (same architecture, never trained) already yields R²=0.70 for the belief probe. This is high, and demands explanation.

The reason: beliefs are deterministic functions of the token sequence. The transformer's token embeddings map each of the 3 tokens to a distinct 64D vector. Combined with positional embeddings (which encode where in the sequence each token appears), the residual stream provides a rich representation of the token history — even before training. Random projections through untrained layers partially preserve this structure.

The relevant comparison is MSE: training reduces MSE from 0.071 to 0.004, a 16.4x improvement. Training eliminates 94% of the remaining error beyond what the architecture provides for free.

#### Temporal split (MSE = 0.057, ratio = 13.1x)

The probe is trained on positions 0-24 (first half of each sequence) and tested on positions 25-49 (second half), and vice versa. The test MSE (0.057) is close to the untrained baseline (0.071).

This reveals an important property: **the linear map between activations and beliefs does not generalize across positions.** The same belief state at position 5 and position 30 is encoded in different directions in the residual stream. This is because the transformer uses absolute positional embeddings — position information is baked into every activation.

There is no single "belief direction" in the residual stream. The encoding is position-specific. The pooled probe (MSE=0.004) works because it trains on all positions simultaneously, finding a weighted compromise that works across positions. But the representation is fundamentally entangled with position.

#### MSE decomposition

The controls establish a hierarchy:

| Level | MSE | What it represents |
|---|---|---|
| Shuffle | 0.236 | No structure (random pairing) |
| Untrained | 0.071 | Architecture alone (embeddings + random weights) |
| Temporal split | 0.057 | Architecture + position-independent structure only |
| Trained | 0.004 | Full learned representation |

### Timescale separation

Does the transformer's representation reflect the different timescales of driver and transducer inference?

A single regression is fit across all positions, then evaluated per position. MSE (not R²) is the primary metric, because R² at early positions is unstable — at position 0, the driver marginal has zero variance (every sequence starts from the same stationary distribution with theta=0.5 exactly), making R² undefined.

Findings from the final layer (L3):

| Position | Driver MSE | Transducer MSE | Ratio (driver/trans) |
|---|---|---|---|
| 5 | 0.0016 | 0.0023 | 0.7 |
| 10 | 0.0021 | 0.0024 | 0.9 |
| 20 | 0.0027 | 0.0021 | 1.3 |
| 30 | 0.0025 | 0.0019 | 1.3 |

The driver MSE is consistently equal to or higher than the transducer MSE, though the difference is modest (about 1.3x in the stable middle range). The transducer is a slightly easier inference problem, consistent with it being a faster variable.

Both MSE curves spike at positions 45-49. This is a methodological artifact: a single linear map fit across all positions is a compromise that works best in the middle of the sequence and worst at the edges, where positional embedding effects are strongest.

The concatenated probe (all layers) shows 2-3x lower MSE everywhere compared to the final layer alone, confirming that belief information is distributed across layers.

### Subspace analysis

Do the driver and transducer occupy separate directions in the residual stream?

The probe yields a weight vector for the driver (a 256D direction in the concatenated activation space) and three weight vectors for the transducer marginal (a 3D subspace in the same space). We measure the overlap: what fraction of the driver direction lies within the transducer subspace?

**Observed overlap: 0.110**

This number alone is uninterpretable. We need to compare it against null distributions.

**Naive null (random directions in 256D):** mean overlap = 0.100, z-score = +0.22. In 256 dimensions, any two random directions are approximately orthogonal. The observed overlap of 0.110 is indistinguishable from random directions. This null is uninformative — it tells us nothing about the model's representational choices.

**Belief-projection null (random linear functions of the belief state):** mean overlap = **0.844**, z-score = **-4.69**. This is the correct null. It asks: if we pick arbitrary linear projections of the 6D belief state and map them through the model's encoding, how much do their weight vectors overlap?

The answer: a lot. The mean overlap is 0.84. This is because the model encodes 6D beliefs through a low-rank linear map into the 256D residual stream. All belief-relevant information is packed into a small subspace (~6D effective). Random belief projections, mapped through this compact encoding, land in overlapping directions.

But the driver and transducer have overlap of only 0.110 — **4.7 standard deviations below** the null mean. The model has specifically separated these two quantities into distinct directions, far more than random belief projections would be.

This is surprising because driver and transducer are NOT orthogonal in belief space: they share information (the driver marginal is a sum of belief components, and the transducer marginal includes some of the same components). If the model simply embedded the 6D belief linearly into the residual stream without any special structure, these quantities would produce overlapping weight vectors. The fact that they don't means the model's encoding actively rotates driver and transducer information into separate directions.

The per-layer analysis shows that separation is strongest in early layers (L0 z=-3.41, L1 z=-3.56) and weakens toward the output layer (L3 z=-2.61, but still significant). This makes sense: the final layer must combine driver and transducer information to compute next-token probabilities, which depend on the full composite state.

## Summary of findings

1. **A 4-layer transformer trained on next-token prediction over a hierarchical HMM linearly encodes the full 6D Bayesian posterior** in its residual stream (MSE=0.004, R²=0.982). The sequence-level cross-validation (1.00x) and shuffle control (54.2x) confirm this is genuine.

2. **Training is essential but the architecture helps.** The randomly initialized model already provides R²=0.70 (MSE=0.071). Training reduces MSE by 16.4x, eliminating 94% of the remaining error beyond what token/positional embeddings provide for free.

3. **The encoding is position-specific.** The temporal split control (13.1x) shows the linear map does not generalize across positions. The model uses absolute positional embeddings, so the same belief at different positions is encoded in different directions.

4. **The network allocates deeper computation to the harder inference problem.** The transducer state (fast variable, determined by recent tokens) is well-captured at L0 (R²=0.954). The driver state (slow variable, requiring statistical integration over ~20 tokens) requires processing through all layers (L0 R²=0.556 → L3 R²=0.895).

5. **Driver and transducer are encoded in significantly separated subspaces** (z=-4.69 against the belief-projection null), more orthogonal than random linear functions of the belief state. This is a representational choice, not a geometric inevitability — the model actively organizes slow and fast latent variables into distinct directions.

6. **The model is near-optimal but not Bayes-optimal.** The converged loss of 0.931 nats is 0.22% above the entropy rate of 0.929 nats, likely reflecting the finite context window.
